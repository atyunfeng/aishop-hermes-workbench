## 基础能力

- [ ] 两台手机均在 15 秒内上线，心跳间隔约 5 秒。
- [ ] 通知、Accessibility 与 MediaProjection 显示就绪。
- [ ] 千牛、抖店/飞鸽、微信、企业微信、QQ 的测试通知各生成一次入站事件，重复通知不重复建单。
- [ ] 开机恢复在默认关闭时不启动；显式开启且已配对时才恢复前台服务。
- [ ] 暂停、继续、人工接管、停止命令均被手机明确确认。
- [ ] 断网超过 30 秒后租约回收，恢复或换机能从最后成功步骤继续。
- [ ] 截图/预览只在系统授权期间上传，停止服务后 MediaProjection 立即结束。

## 安全与异常

- [ ] 验证码、登录失效和未知页面均停止并进入 `HUMAN_TAKEOVER`。
- [ ] 未审批的退款、退货、资金、账号、删除、加好友、群发动作均无法执行。
- [ ] 重复消息、重复心跳和重复步骤结果不产生重复回复或重复售后。
- [ ] 模拟模式始终显示 `SIMULATED`，真实设备证据始终显示 `DEVICE`。
- [ ] 操作员能在 5 秒内暂停任务或接管指定手机。
- [ ] productionRelease 拒绝 HTTP 网关；正式签名包的证书、升级安装和 SHA-256 已记录。
- [ ] 设备令牌轮换后旧令牌失效，撤销后心跳与证据上传均返回 401。
